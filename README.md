# 💈 BarberApp - Barber Randevu Sistemi
**By Calvin - Ankara**

Berber defterine son! Müşteri randevularını kaybetmeyen sistem.

### ✨ Özellikler
- Müşteri ekle (Ad, Telefon, Tarih, Saat)
- Listele / Sil
- Kapansa bile silinmez (barber_appointments.txt)
- Tek tıkla açılır - kurulum yok

### 🚀 Kurulum
1. Releases'den BarberApp.jar indir
2. Çift tıkla - bitti!
